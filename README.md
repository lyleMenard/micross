## Micross

This is a small React project for fun! My goal is to have a working Picross implementation with the following features:
 - Random and custom puzzles
 - Timed puzzle completion with leaderboards
 - Randomized puzzles verified for unique solutions
 - Polish and multiple methods of input
 - Single-row click-and-drag tile filling

### Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
